# BUNGBOY FITNESS LIBRARY

เว็บไซต์สารบัญบทความและวิดีโอสำหรับอ่านส่วนตัวจากลิงก์เพจ Bungboy ที่ผู้ใช้รวบรวมไว้ ไม่ใช่เว็บไซต์อย่างเป็นทางการของเพจ

## เปิดเว็บไซต์

**https://chakritago.github.io/fitness/**

เมื่อเปิดใช้งาน GitHub Pages ตามขั้นตอนด้านล่าง เว็บไซต์จะมี:

- **527 หัวข้อไม่ซ้ำ** พร้อมชื่อเรื่องและลิงก์ต้นฉบับ Facebook/YouTube
- ค้นหาภาษาไทย แยกหมวดหมู่ กรองวิดีโอ เรียงตามชื่อ และเส้นทางอ่านสำหรับมือใหม่
- บุ๊กมาร์ก กรองเรื่องที่ยังไม่อ่าน ทำเครื่องหมายอ่านแล้ว และเขียนโน้ตส่วนตัว
- ส่งออก/นำเข้าบุ๊กมาร์ก สถานะอ่าน และโน้ตเป็นไฟล์ JSON เพื่อสำรองหรือย้ายเบราว์เซอร์
- **แสดงโพสต์ Facebook และวิดีโอ YouTube แบบฝังอัตโนมัติ** เมื่อเลื่อนถึงโพสต์ (lazy loading) พร้อมปุ่มสลับเป็นรายการย่อเพื่อประหยัดข้อมูล
- โหมดสว่าง/มืด ปรับขนาดตัวอักษร รองรับมือถือ และเปิดโพสต์ต้นฉบับได้จากทุกหัวข้อ

## การแสดงโพสต์แบบฝังอัตโนมัติ

เว็บไซต์เริ่มต้นในโหมด **ฝังโพสต์อัตโนมัติ** โดยโหลด iframe เฉพาะรายการที่ใกล้ปรากฏบนหน้าจอ (12 รายการต่อชุด) และเมื่อกดเปิดหน้าต่างอ่าน ระบบจะพยายามฝังโพสต์ทันที ไม่ต้องกดปุ่มแสดงโพสต์อีก สามารถสลับเป็น **รายการย่อ** (24 หัวข้อต่อชุด) ได้ และเว็บไซต์จำโหมดที่เลือกในเบราว์เซอร์

การฝังอาศัยปลั๊กอินอย่างเป็นทางการของ Facebook และตัวเล่น YouTube; **ไม่รับประกันว่าจะฝังได้ทุกลิงก์** เพราะโพสต์อาจถูกลบ ตั้งค่าเป็นส่วนตัว ต้องเข้าสู่ระบบ หรือผู้ให้บริการปฏิเสธการฝัง โดยเฉพาะลิงก์ที่กู้คืนจากรายการที่ถูกตัด ทุกโพสต์มีลิงก์ให้เปิดต้นฉบับเสมอ การโหลด iframe จะเชื่อมต่อกับ Facebook/YouTube โดยตรง และอาจส่งข้อมูลการใช้งานไปยังผู้ให้บริการนั้น

## แหล่งข้อมูลและความถูกต้องของลิงก์

| สถานะ | จำนวน |
| --- | ---: |
| URL ตามรายการที่ส่งมา | 324 |
| URL สร้างใหม่จากรหัสโพสต์/รูปที่ยังเห็นได้ในลิงก์ถูกตัด | 201 |
| URL ไม่สมบูรณ์ ไม่สามารถระบุปลายทางแน่นอนได้ | 2 |
| **รวม** | **527** |

สถานะนี้หมายถึงรูปแบบลิงก์ **ไม่ใช่การตรวจสอบว่าโพสต์ยังเปิดได้จริง** และ Facebook อาจกำหนดให้เข้าสู่ระบบ มี 2 หัวข้อแรกที่เพิ่มคืนจากรายการต้นฉบับ คือ “วัตถุประสงค์ของเพจ bungboyofficial” และ “สาเหตุที่ต้องอ่านบทความให้ครบก่อนเริ่มปฏิบัติตามเพจ”

**เว็บนี้เป็นสารบัญ ไม่ใช่การคัดลอกบทความเต็ม**: ชื่อเรื่องและลิงก์มาจากรายการของผู้ใช้ ไม่ได้ดึงหรือเผยแพร่เนื้อหาต้นฉบับโดยไม่ได้รับอนุญาต ข้อความด้านโภชนาการและสุขภาพในชื่อโพสต์ไม่ใช่การยืนยันข้อเท็จจริงทางการแพทย์

## เปิดใช้ GitHub Pages

1. ไปที่ [Settings → Pages](https://github.com/chakritago/fitness/settings/pages)
2. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
3. เลือก Branch: **main**, Folder: **/(root)** และกด **Save**
4. รอให้ GitHub Pages เผยแพร่ แล้วเปิด https://chakritago.github.io/fitness/

GitHub Repository นี้เป็น **Public** เว็บไซต์จึงเข้าถึงได้โดยบุคคลทั่วไป แม้จะตั้งค่า `noindex` เพื่อลดการแสดงในเครื่องมือค้นหา ก็ไม่ได้เป็นระบบล็อกอินหรือป้องกันการเข้าถึง

## การเก็บบันทึกส่วนตัว

บุ๊กมาร์ก สถานะอ่านแล้ว และโน้ตอยู่ใน `localStorage` ของเบราว์เซอร์บนอุปกรณ์นั้น **ไม่ได้อัปโหลดไป GitHub** และไม่ซิงก์ข้ามเครื่องโดยอัตโนมัติ ควรใช้ปุ่ม **ส่งออก** เพื่อสำรองข้อมูลก่อนล้างข้อมูลเบราว์เซอร์ ปุ่ม **นำเข้า** จะเขียนทับข้อมูลการอ่านเดิมบนอุปกรณ์นั้น

## โครงสร้างโปรเจกต์

- `index.html` — หน้าเว็บและรูปแบบการแสดงผล
- `data.js` — รายชื่อเรื่อง URL หมวด และสถานะลิงก์
- `app.js` — ค้นหา ตัวกรอง การอ่าน บันทึก และนำเข้า/ส่งออก
- `favicon.svg` — ไอคอนเว็บ
- `.nojekyll` — ใช้ไฟล์แบบ Static โดยไม่ผ่าน Jekyll

ไม่ต้องใช้ Backend หรือ API key สามารถเปิด `index.html` โดยตรงหรือรัน `python -m http.server 8080` ในโฟลเดอร์นี้
