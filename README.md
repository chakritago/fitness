# BUNGBOY FITNESS LIBRARY

เว็บไซต์ดัชนีอ่านเรื่องการออกกำลังกายและโภชนาการ รวบรวมจากรายการ **หัวข้อ + URL** ที่ผู้ใช้ส่งให้ ไม่ใช่เว็บไซต์ทางการของเพจ ไม่คัดลอกเนื้อหาต้นฉบับหรืออ้างว่าได้ตรวจสอบข้อเท็จจริงในโพสต์

## เว็บไซต์

เผยแพร่จาก repository `chakritago/fitness` ที่สาขา `main` โฟลเดอร์ `/ (root)`:

**https://chakritago.github.io/fitness/**

คุณสมบัติ: ค้นหาชื่อเรื่องภาษาไทย, หมวดเรื่อง, คัดกรองวิดีโอ, เรียงตามชื่อ, บุ๊กมาร์ก, ทำเครื่องหมายอ่านแล้ว, สมุดจดรายบทความ, ธีมมืด/สว่าง, เพิ่มขนาดตัวอักษร, รองรับมือถือ, แชร์ลิงก์บทความในไซต์ และลองแสดงโพสต์ผ่าน iframe ตามข้อจำกัดของ Facebook/YouTube

## ข้อมูลและสถานะลิงก์

- รายการรับเข้า: **538** URL
- รวบรวมแบบไม่ซ้ำ: **525** หัวข้อ
- URL คงตามต้นฉบับ: **322**
- URL ที่สร้างใหม่จาก ID เมื่อข้อมูลเดิมถูกตัดด้วย `...`: **201** (ยังไม่ยืนยันว่าพาไปยังโพสต์นั้นได้)
- URL ไม่สมบูรณ์และกู้คืนไม่ได้: **2** (เว็บจะเปิดหน้าเพจแทน)

*สถานะ URL เป็นการตรวจรูปแบบ ไม่ใช่การยืนยันว่าโพสต์เข้าถึงได้จริง* เนื่องจาก Facebook บล็อกการอ่านโพสต์ตัวอย่างผ่านเครื่องมือ ณ วันที่สร้างเว็บ (13 ตุลาคม 2026)

## ข้อจำกัดและลิขสิทธิ์

เว็บไซต์นี้เป็น **สารบัญลิงก์** ไม่ใช่คลังบทความเต็ม: Facebook อาจจำกัดการเข้าถึง และไม่ควรนำเนื้อหาที่มีลิขสิทธิ์ของบุคคลภายนอกมาเผยแพร่ซ้ำทั้งหมดโดยไม่มีสิทธิ์ เนื้อหาในโพสต์บางส่วนอาจเปลี่ยนแปลง ถูกลบ หรือต้องเข้าสู่ระบบ

หัวข้อเกี่ยวกับแคลอรี การเผาผลาญ และการออกกำลังกายเป็นชื่อเรื่องตามต้นทาง **ไม่ใช่คำรับรองด้านวิทยาศาสตร์หรือคำแนะนำเฉพาะบุคคล**

## พัฒนา / ใช้งานในเครื่อง

ไม่มีระบบ build หรือ Backend เปิด `index.html` ในเบราว์เซอร์ได้ (ข้อมูลโหลดด้วย `data.js`) หรือใช้ local server:

```sh
python -m http.server 8080
```

แล้วเปิด http://localhost:8080

ไฟล์หลัก: `index.html`, `app.js`, `data.js`, `favicon.svg` และ `.nojekyll` ข้อมูลรายการตั้งต้นไม่ต้องใช้ API Key

## เผยแพร่บน GitHub Pages

1. ไฟล์เว็บถูกจัดไว้ที่ root ของสาขา `main` แล้ว
2. เข้า [Settings → Pages](https://github.com/chakritago/fitness/settings/pages) เลือก **Deploy from a branch**
3. ตั้ง Branch เป็น `main`, Folder เป็น `/(root)` แล้วกด **Save**
4. เว็บไซต์จะพร้อมใช้งานที่ **https://chakritago.github.io/fitness/** หลังการเผยแพร่เสร็จสิ้น

> เมื่อนำขึ้น GitHub Pages ต้องตรวจว่าไฟล์ `data.js` ถูกอัปโหลดครบ หากหน้าเว็บแสดง 0 หัวข้อ ให้ตรวจการโหลดไฟล์นี้ใน DevTools / Network
